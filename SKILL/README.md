# 经营分析报告

基于产品需求文档实现的经营数据分析与报告系统，提供多维度业务洞察与数据钻取能力。

## 功能模块

- **营业概况** - 核心仪表板：关键指标、趋势图、渠道占比、渠道明细表
- **订单详情** - 从昨日/本周订单量钻取，支持筛选
- **支付方式** - 各支付方式金额及占比
- **交易明细** - 订单商品明细
- **流量分析** - 从本周收入钻取，UV/PV 趋势、渠道访问占比
- **用户画像** - 年龄段分布
- **留存分析** - 新用户、1日/7日留存
- **营销活动** - 活动效果与费用
- **销售报表** - 商品销售额、毛利、库存
- **客户分布** - 地域分布
- **门店排名** - 门店业绩排行
- **商品销售** - 商品维度分析
- **渠道分析** - 多渠道对比
- **用户行为** - 用户画像与访问来源
- **交易明细** - 独立交易查询页
- **报表管理** - 报表配置与导出

## 技术栈

- React 18 + TypeScript
- Vite
- Ant Design 5
- ECharts (echarts-for-react)
- React Router 6
- dayjs

## 快速开始

### 环境要求

- Node.js 18+
- npm 或 pnpm

### 安装与运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

启动后访问 http://localhost:5173

## 数据钻取流程

1. **营业概况** → 点击「昨日订单量」→ **订单详情**
2. 订单详情 → 点击「支付方式」→ **支付方式**
3. 订单详情 → 点击「查看明细」→ **交易明细**
4. **营业概况** → 点击「本周收入」→ **流量分析**
5. 流量分析 → 查看用户画像/留存 → **用户画像** / **留存分析**
6. 用户画像 → 查看营销活动 → **营销活动** → **销售报表**
