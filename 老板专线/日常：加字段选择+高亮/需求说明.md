# 报表页面需求说明文档

## 1. 文档信息

- 文档名称：报表页面需求说明文档
- 适用页面：水果每日销售量报表页（手机端）
- 版本：v1.1
- 日期：2026-04-23
- 作者：产品/研发（待补充）

## 2. 需求背景与目标

当前报表页在移动端查看时，需要提升字段配置效率与数据浏览体验，同时保持原有页面风格与数据内容不变。  
本次改造目标如下：

- 在不改变原图数据内容与视觉风格的前提下，提升字段选择能力
- 提升表格交互反馈（行点击高亮）
- 优化表格信息结构（新增序号、两行展示规则）
- 提升横向浏览效率（滑动时首2列固定）
- 支持手机端竖屏与横屏两种展示场景

## 3. 范围说明

### 3.1 本次范围（In Scope）

- 当前报表页面（水果每日销售量）
- 顶部操作区字段选择能力
- 表格行交互与表格列展示逻辑
- 表格横向滑动冻结列能力（首2列固定）
- 字段选择抽屉（底部呼起）
- 手机端横屏/竖屏样式适配
- 中文文案展示

### 3.2 非本次范围（Out of Scope）

- 报表数据来源、计算逻辑、后端接口变更
- 原始数据值内容修改
- 整体品牌风格与视觉体系重构
- PC 端样式专项优化

## 4. 页面不变项

以下内容必须保持不变：

- 报表主题与核心布局结构保持原样
- 已有数据字段值不被改写，不新增解释性数据文案
- 页面整体风格与设计基调保持与原图一致

## 5. 功能需求

## 5.1 顶部按钮调整

- 在【设置】按钮左侧新增【字段选择】按钮
- 字段按钮展示当前已选字段数量，格式：`字段(n)`
- 按钮文案与弹层文案均为中文

## 5.2 字段选择（底部抽屉）

- 点击【字段选择】后，从底部呼起抽屉面板
- 抽屉包含：
  - 顶部：标题“选择字段”、已选数量徽标、关闭按钮、编辑按钮（展示态）
  - 中部：字段卡片区（支持多选）
  - 底部：`重置` 与 `确定` 两个操作按钮
- 字段卡片支持多选，选中/未选中状态视觉可区分
- 点击 `重置`：恢复全部字段为选中
- 点击 `确定`：应用字段选择结果到表格列显示
- 点击遮罩或关闭按钮：关闭抽屉（不强制变更当前表格展示）

## 5.3 表格行高亮

- 用户点击任意数据行后，该行高亮显示
- 同一时刻仅允许一行高亮
- 再点击其他行时，高亮跟随切换到新行

## 5.4 序号与两行展示

- 新增“序号”列，按当前列表顺序展示（1、2、3...）
- 表格单元采用两行容器结构：
  - 第一行：展示该列原始数据值
  - 第二行：保留展示位，不引入新的解释性文案
- 商品名称需支持单行展示（超出时省略号截断）

## 5.5 横屏/竖屏适配

- 同一页面需支持手机竖屏与横屏两种样式
- 竖屏：标题字号与间距适配单手浏览
- 横屏：表格区域可视高度提升，便于同屏查看更多数据行
- 字段选择抽屉在横竖屏下均保持底部呼起形态

## 5.6 首2列固定（滑动冻结列）

- 表格发生横向滑动时，前两列保持固定不随内容区域横向移动
- 固定列范围定义：
  - 第1列：序号
  - 第2列：商品名称
- 第3列及之后字段可随横向滚动区域移动
- 固定列与可滚动列之间需有清晰分隔（边框或阴影），避免视觉重叠
- 在竖屏与横屏两种模式下均需生效

## 6. 交互流程

### 6.1 字段选择流程

1. 用户点击【字段选择】按钮  
2. 底部抽屉弹出，展示字段卡片与底部操作按钮  
3. 用户勾选/取消字段  
4. 用户点击：
   - `重置`：恢复默认全选
   - `确定`：应用字段显示并关闭抽屉
   - `关闭/遮罩`：关闭抽屉

### 6.2 行高亮流程

1. 用户点击某一数据行  
2. 系统取消其他行高亮  
3. 当前点击行显示高亮状态

### 6.3 横向滑动与固定列流程

1. 用户左右滑动表格区域  
2. 第1列与第2列保持固定位置  
3. 第3列及后续列按滑动方向移动  
4. 用户仍可正常点击任意可见行触发行高亮

## 7. 显示规则与边界条件

- 字段数量显示始终与当前勾选数量一致
- 未勾选字段在表格中隐藏，勾选字段显示
- 若用户执行 `重置`，字段恢复全选并更新数量
- 原始数据值不做格式追加（例如不额外拼接“元”“件”“周一”等）
- 商品名称始终单行展示，避免换行挤压
- 横向滑动时首2列固定，不因字段显示变化而失效

## 8. 非功能要求

- 移动端可用性：触控区域清晰，底部抽屉操作可达
- 可读性：表格头与数据分层明确，选中态可辨识
- 响应式：横竖屏切换后布局稳定、不重叠
- 兼容性：主流移动浏览器可正常打开与交互

## 9. 验收标准（Given / When / Then）

### 9.1 字段选择按钮

- Given 页面加载完成  
  When 查看顶部操作区  
  Then 【设置】左侧存在【字段选择】按钮，且显示 `字段(n)`

### 9.2 字段抽屉展示

- Given 用户点击【字段选择】  
  When 抽屉弹出  
  Then 抽屉从底部呼起，且为中文文案，包含字段卡片与底部 `重置/确定` 按钮

### 9.3 字段多选与应用

- Given 抽屉已打开  
  When 用户取消勾选某字段并点击 `确定`  
  Then 表格对应列隐藏，按钮数量同步变化

### 9.4 重置行为

- Given 用户修改过字段勾选状态  
  When 点击 `重置`  
  Then 字段恢复全选，数量显示恢复为全量

### 9.5 行高亮

- Given 表格有多条数据  
  When 点击任意行  
  Then 该行高亮，且同时仅有一行高亮

### 9.6 序号与两行结构

- Given 表格加载完成  
  When 查看任意数据行  
  Then 存在“序号”列，且单元格按两行容器展示，商品名称第一行单行显示

### 9.7 横竖屏适配

- Given 页面在手机端打开  
  When 切换竖屏与横屏  
  Then 页面均可正常浏览与操作，字段抽屉样式与交互可用

### 9.8 首2列固定

- Given 表格存在横向滚动  
  When 用户左右滑动表格  
  Then “序号”和“商品名称”两列保持固定，其他列随滚动移动
